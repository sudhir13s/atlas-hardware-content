## Description
AMD announced the Radeon RX 6000 Series on 28 October 2020; the RX 6900 XT was to be available on
8 December 2020. RDNA 2 adds a fixed-function Ray Accelerator to each compute unit and the 128 MB
Infinity Cache, and AMD describes it as a foundation for next-generation consoles as well as PCs.
