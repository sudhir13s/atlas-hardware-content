## Description
Volta introduced the first-generation Tensor Core — a dedicated mixed-precision matrix-multiply-
accumulate unit. By computing FP16 matrix products with FP32 accumulation in hardware, it delivered an
order-of-magnitude throughput gain on neural-network training and set the direction for every AI GPU
that followed.
