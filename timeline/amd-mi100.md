## Description

AMD announced the Instinct MI100 on 16 November 2020 as the first GPU with its CDNA architecture. CDNA
adds Matrix Core Engines with Matrix Fused Multiply-Add (MFMA) instructions and, unlike the
graphics-oriented RDNA family, removes the fixed-function graphics hardware, according to AMD's CDNA white paper.
